# ScamShield 🛡️

### AI-Powered SMS Scam Detector

ScamShield is a beginner-friendly AI project developed for the Veritas AI International High School Hackathon 2026.

## Problem
Many people receive suspicious SMS messages that may contain scams, fake prizes, or fraudulent requests.

## Our Solution
ScamShield uses machine learning to analyse SMS messages and predict whether they are spam or normal messages.

## Technology
- Python
- Machine Learning
- TF-IDF
- Naive Bayes
- Streamlit

## Dataset
SMS Spam Collection Dataset.

## Team
Veritas AI Hackathon Team

## Disclaimer
This is an educational prototype. Its predictions may be incorrect and should not be treated as proof that a message is safe or fraudulent.
